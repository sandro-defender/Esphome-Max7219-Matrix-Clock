# Bundled fonts

Font source files live in this repository so ESPHome builds download
reproducible assets from the same release as the packages, and so the web
configurator can rasterise the very same files instead of a web-font
approximation.

Matrix 2px, Dot Matrix and Pixel Clock 6×8 are original pixel designs generated
by this repository. The two MD faces convert bitmap tables from Marco Colli's
MD_MAX72XX/MD_Parola Arduino libraries (LGPL-2.1-or-later). Quantico Bold and the
two Georgian Noto families come from the official
[Google Fonts repository](https://github.com/google/fonts) under the SIL Open
Font License 1.1; the Georgian families are uncompiled source candidates — they
remain licensed and measured but are not part of any release font package.

Five faces are packaged under `packages/fonts/*.yaml` (local equivalents in
`packages/local_fonts/*.yaml`). The default build and the installer compile
**Pixel Clock 6×8** (initial face) and **Matrix 2px**, with the built-in
**Compact 5×7** always available; Dot Matrix, MD Parola Numeric 7-Segment and
MD MAX72XX System are optional. The policy and package layout are documented in
[packages/fonts/README.md](../packages/fonts/README.md). Keeping the Georgian
sources out of the default build preserves ESP8266 RAM while leaving a licensed
path to a future message face.

## How the firmware uses them

Per-face packages under `packages/fonts/*.yaml` download their font with
`type: web` and `bpp: 1`, pinned to the same tag as the package files, define one
`-DMAX7219_FONT_*` build flag and append their option to `clock_font` via
`!extend`:

```yaml
font:
  - id: font_md_max72xx_system_source
    file:
      type: web
      url: ${fonts_base_url}/md-max72xx-system/MDMax72xxSystem.ttf   # raw GitHub URL + ${project_ref}
    size: 8
    bpp: 1
    glyphs:
      - "0123456789:.-/%!?+ "
```

`packages/fonts_web.yaml` wraps the default pair; `packages/fonts_local.yaml`
reads all five validated faces from `fonts/` for offline development, metric
checks and preview glyph generation. `tests/test_config.py` asserts the per-face
web packages and `packages/fonts_local.yaml` stay identical (ids, sizes, `bpp`,
glyphs), that every subset of compiled fonts is selectable in Home Assistant and
wired into the display lambda, and that the glyph set covers every character the
renderer can print.

ESPHome restores `Clock font` by numeric option index (`restore_value: true`), so
changing which optional extras are compiled may remap a saved index on reboot;
out-of-range indices fall back to `initial_option`, unmatched options fall back
to `Compact 5×7`, and "Restore display defaults" always resets to `Compact 5×7`.

Only rasterised glyphs are compiled into firmware, never the TTF/OTF files.
External faces intentionally contain only numeric/status glyphs; the built-in
compact font renders Latin messages. The Home Assistant message action stores 47
UTF-8 bytes — up to 15 Georgian letters plus a terminator — and truncates on
code-point boundaries, so a half Georgian character can never reach the buffer.

## Measurements (ESPHome `pt_to_px()` metrics)

Measured two ways, both reproducible in the repository: `tests/test_config.py`
uses freetype-py with ESPHome's advance calculation
(`pt_to_px(horiAdvance)`), and `web-configurator/scripts/generate_glyphs.py`
rasterises the same files through FreeType for the browser preview.

| Font | `size` | worst-case `88:88:88` width | Tallest digit | Fits 48×8 | Notes |
|---|---|---|---|---|---|
| Dot Matrix | 8 | 48 px | 8 px | yes, exact fit | original single-LED-dot digits; `HH:MM` is 31 px on a 32x8 panel |
| Matrix 2px | 8 | 48 px | 8 px | yes, exact fit | generated pixel font; every number stroke is exactly 2 px thick |
| Pixel Clock 6×8 | 8 | 48 px | 8 px | yes, exact fit | rounded six-column digits with two-column edges |
| MD Parola Numeric 7-Segment | 8 | 32 px | 7 px | yes | seven-segment bitmap conversion; 16 px headroom |
| MD MAX72XX System | 8 | 34 px | 7 px | yes | MD_MAX72XX `_sysfont` numerals; 14 px headroom |
| built-in 5×7 fallback | - | 42 px | 7 px | yes, always available | needs no download |

Matrix 2px is additionally asserted pixel-for-pixel against its design table
(`test_matrix_2px_font_is_pixel_exact_with_two_pixel_lines`), so hinting can
neither thin nor thicken its two-pixel strokes. The renderer checks the width at
runtime and degrades in a fixed order: full `HH:MM:SS` → `HH:MM` plus the
bottom-row seconds bar → built-in fallback font.

Glyph sets are limited on purpose (digits, separators, `%`, `.`, `-`, `/`, `!`,
`?`, `+` and space); messages fall back to the built-in uppercase face. Fonts are
downloaded and rasterised at **build time** — the ESP8266 never downloads
anything at runtime.

## Adding another font

1. Confirm its redistribution licence and store the licence text beside it.
   Generated faces document their generator script instead.
2. Add the file under `fonts/<family>/`.
3. Add a per-face `packages/fonts/<slug>.yaml` package **and** a matching entry
   in `packages/fonts_local.yaml` with the same `id`, `size`, `bpp` and glyphs.
4. Map the new `id` in `FONT_OPTION_BY_ID` in `tests/test_config.py` and guard
   its instantiation in `packages/display.yaml`.
5. Add the face to `FONT_CATALOG` in `web-configurator/src/fontCatalog.ts` and
   run `python3 web-configurator/scripts/generate_glyphs.py`.
6. `python3 tests/test_config.py` — fails if the font does not fit the
   worst-case numeric clock on 48×8, if a glyph is missing, or if it is not
   selectable.
7. `npm --prefix web-configurator test` — fails if configurator and firmware
   disagree about the available fonts.
8. Measure ESP8266 flash usage after a full compile and document it in
   [packages/fonts/README.md](../packages/fonts/README.md) with SDK version and
   date.
