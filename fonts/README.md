# Bundled fonts

These font source files are stored in this repository so ESPHome builds can
download reproducible assets directly from the same release as the package
configuration. The web configurator rasterises the very same files, so its
preview shows the real glyphs instead of a web-font approximation.

Matrix 2px, Dot Matrix and Pixel Clock 6×8 are original pixel designs generated
by this repository (see "Adding another font" below). The two MD faces convert
bitmap tables from Marco Colli's MD_MAX72XX/MD_Parola Arduino libraries, which
are LGPL-2.1-or-later. Quantico Bold and the two Georgian Noto families come
from the official [Google Fonts repository](https://github.com/google/fonts)
under the SIL Open Font License 1.1 and remain uncompiled source candidates.

Five validated 8-row choices are packaged under `packages/fonts/*.yaml` (and in
`packages/fonts_local.yaml` for offline builds and metrics). The web configurator
ships **Pixel Clock 6×8** by default (as the initial active face, with every
other face an optional extra); the pinned release example
(`examples/release.yaml`) bundles the **Matrix 2px** + **Dot Matrix** pair. This
keeps the remaining source files available without consuming ESP8266 RAM
unnecessarily.

## How the firmware uses them

Per-face packages under `packages/fonts/*.yaml` (release) download their font
with `type: web` and `bpp: 1`, pinned to the same tag as the package files,
define a `-DMAX7219_FONT_*` build flag, and append their option to `clock_font`
via `!extend`:

```yaml
font:
  - id: font_md_max72xx_system_source
    file:
      type: web
      url: ${fonts_base_url}/md-max72xx-system/MDMax72xxSystem.ttf   # github raw URL + ${project_ref}
    size: 8
    bpp: 1
    glyphs:
      - "0123456789:.-/%!?+ "
```

`packages/fonts_web.yaml` is a convenience wrapper for the default Matrix 2px +
Dot Matrix release pair. `packages/fonts_local.yaml` reads all five validated
faces from `fonts/` for offline development, metric checks, and preview glyph
generation. `tests/test_config.py` asserts that the per-face web packages and
`packages/fonts_local.yaml` stay identical (ids, sizes, `bpp`, glyphs), that
every subset of compiled fonts is selectable in Home Assistant and wired into
the display lambda, and that the glyph set covers every character the renderer
can print. Because ESPHome restores `Clock font` by numeric option index
(`restore_value: true`), changing which optional extra fonts are compiled may
remap a saved extra index on reboot; out-of-range indices fall back to
`initial_option`, any unmatched option falls back to `Compact 5x7`, and
`Restore display defaults` always resets `Clock font` to `Compact 5x7`.

Only rasterised glyphs are compiled into firmware, never the TTF/OTF files.
External faces intentionally contain only numeric/status glyphs. The built-in
compact font renders Latin messages. Noto Sans Georgian and Noto Serif
Georgian remain licensed source candidates in the repository, but are not part
of the default firmware until an ESP8266-safe message-font design is validated.

The Home Assistant message action stores 47 UTF-8 bytes. That is up to 15
Georgian letters (plus a terminator); truncation is code-point safe and never
leaves half of a Georgian character in the display buffer.

## Measurements (ESPHome `pt_to_px()` metrics)

Measured two ways, both in the repository:

* `tests/test_config.py` uses freetype-py with ESPHome's advance calculation
  (`pt_to_px(horiAdvance)`, i.e. rounding up to whole pixels);
* `web-configurator/scripts/generate_glyphs.py` rasterises the same files with
  FreeType through Pillow, which is what the browser preview paints.

| Font | `size` | worst-case `88:88:88` width | Tallest digit | Fits 48×8 | Notes |
|---|---|---|---|---|---|
| Dot Matrix | 8 | 48 px | 8 px | yes, exact fit | original single-LED-dot digits; `HH:MM` is 31 px wide for 32x8 panels |
| Matrix 2px | 8 | 48 px | 8 px | yes, exact fit | generated pixel font; every number stroke is exactly 2 px thick and digits fill all eight rows |
| Pixel Clock 6×8 | 8 | 48 px | 8 px | yes, exact fit | rounded six-column digits with two-column edges |
| MD Parola Numeric 7-Segment | 8 | 32 px | 7 px | yes | seven-segment bitmap conversion; 16 px of headroom |
| MD MAX72XX System | 8 | 34 px | 7 px | yes | the MD_MAX72XX `_sysfont` numerals; 14 px of headroom |
| built-in 5×7 fallback | - | 42 px | 7 px | yes, always available | needs no download |

The automated measurement covers all five validated faces in
`packages/fonts_local.yaml` with ESPHome's monochrome FreeType hinting. Each
`88:88:88` result is at most 48 pixels wide,
and the tallest digit in every face is at most eight rows. Matrix 2px is
additionally asserted pixel-for-pixel against its design table
(`test_matrix_2px_font_is_pixel_exact_with_two_pixel_lines`), so hinting can
neither thin nor thicken its two-pixel strokes. The web configurator
shows the generated bitmap for each face so they can be compared visually.

The renderer checks the width at runtime and degrades in a fixed order:
full `HH:MM:SS` → `HH:MM` plus the bottom-row seconds bar → built-in fallback
font. So an unsuitable font, a narrower panel or a different module count never
clips the clock: it falls back instead. The slide-up animation works per glyph
and is therefore font independent.

Glyph sets are limited on purpose (digits, separators, `%`, `.`, `-`, `/`, `!`,
`?`, `+` and space). Messages fall back to the built-in uppercase face.
Compiling fewer faces and glyphs preserves ESP8266 DRAM headroom.

Fonts are downloaded and rasterised at **build time**; the ESP8266 never
downloads anything at runtime. The Home Assistant font selector switches between
font IDs that are already compiled into the firmware.

## Adding another font

1. Confirm its redistribution license and store the license text beside it.
   Generated faces (like Matrix 2px) document their generator script instead.
2. Add the file under `fonts/<family>/`.
3. Add a per-face `packages/fonts/<slug>.yaml` package **and** matching entry in
   `packages/fonts_local.yaml` with the same `id`, `size`, `bpp` and `glyphs`.
4. Add the option and build flag to `packages/fonts/<slug>.yaml`, map the new
   `id` in `FONT_OPTION_BY_ID` in `tests/test_config.py`, and guard its
   instantiation in `packages/display.yaml`.
6. Add the face to `FONT_CATALOG` in `web-configurator/src/fontCatalog.ts` and
   run `python3 web-configurator/scripts/generate_glyphs.py`.
7. Run `python3 tests/test_config.py` - it fails if the font does not fit the
   worst-case numeric clock on the default 48×8 layout, if a required glyph is missing, or if
   the font is not selectable.
8. Run `cd web-configurator && npm test` - it fails if the configurator and the
   firmware disagree about the available fonts.
9. Measure the ESP8266 flash usage after a full compile and document it here.
