# MD MAX72XX System

This optional 8-pixel clock face is a faithful conversion of the `_sysfont`
bitmap included with [MD_MAX72XX](https://github.com/MajicDesigns/MD_MAX72XX).
MD_Parola uses the same MD_MAX72XX system font; it does not ship an additional
font catalogue.

`MDMax72xxSystem.ttf` is generated by
`scripts/generate_md_max72xx_system_font.py` from the source columns for only
the clock glyph set: `0123456789:.-/%!?+ `. This restricted set is intentional:
it keeps the ESP8266 build small and preserves the project's compact built-in
fallback for message text.

The original system numerals occupy seven of the eight matrix rows. The clock
renderer centres their ink vertically; they are intentionally not scaled or
stretched, so the visible design remains faithful to the Arduino library.
